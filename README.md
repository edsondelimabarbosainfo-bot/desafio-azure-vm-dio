## 📖 Sobre o Projeto

Este repositório foi criado para documentar a realização do desafio prático da Digital Innovation One (DIO) sobre gerenciamento de máquinas virtuais no Microsoft Azure.

O objetivo foi aplicar os conhecimentos adquiridos durante o curso, explorando os principais recursos relacionados à criação, configuração, monitoramento e administração de máquinas virtuais na plataforma Azure.

---

## 🎯 Objetivos de Aprendizagem

Durante a execução deste laboratório foram abordados os seguintes conceitos:

- Criação de Máquinas Virtuais (VMs) no Azure;
- Configuração de recursos computacionais;
- Gerenciamento de armazenamento e discos;
- Configuração de redes virtuais;
- Controle de acesso e segurança;
- Monitoramento e gerenciamento de desempenho;
- Boas práticas de administração em ambientes de nuvem.

---

## 🚀 Etapas Realizadas

### 1. Criação da Máquina Virtual

- Acesso ao Portal Azure;
- Seleção do serviço de Máquinas Virtuais;
- Definição da região de implantação;
- Escolha do sistema operacional;
- Configuração de tamanho e capacidade da VM;
- Configuração de autenticação e acesso.

### 2. Configuração de Rede

- Criação de uma Virtual Network (VNet);
- Configuração de IP Público;
- Configuração de regras de acesso utilizando Network Security Groups (NSG).

### 3. Conexão com a VM - Infelizmente não encontrei um lab para realizar os prints, mas estudei muitos inks incluindo os da Microsoft Learn

- Acesso remoto via RDP ou SSH;
- Testes de conectividade;
- Verificação do funcionamento da máquina virtual.

### 4. Monitoramento - Infelizmente não encontrei um lab para realizar os prints, mas estudei muitos inks incluindo os da Microsoft Learn

- Análise das métricas de desempenho;
- Monitoramento de CPU e memória;
- Verificação de utilização da rede;
- Exploração dos recursos de monitoramento do Azure.

---

## 📚 Principais Aprendizados

Durante este desafio, pude compreender melhor o funcionamento das máquinas virtuais no Azure, desde a sua criação até o monitoramento e gerenciamento operacional.

A prática permitiu reforçar conhecimentos sobre:

- Infraestrutura como Serviço (IaaS);
- Computação em nuvem Microsoft Azure;
- Administração de recursos virtuais;
- Segurança e conectividade em ambientes cloud;
- Monitoramento e gestão de desempenho.
